# Egelsbach starter photograph

`edfe-starter.jpg` is an unmodified official Hessen HVBG WMS GetMap image from
`he_dop_rgb`, distributed under [DL-DE Zero 2.0](https://www.govdata.de/dl-de/zero-2-0).
See [source dataset](https://opendata.hessen.de/de/dataset/atkis-dop-20) and
[SOURCE.json](SOURCE.json) for the geographic bounds, request, byte hash and limits.

`edfe-overview.jpg` is a coarse regional backdrop from the same source and license; its bounds, request and hash are in SOURCE.json under overview.

The photographs are frozen starter assets. Its acquisition date is unknown, and it
supplies no accepted airport elevation, terrain, chart or current operational data.
No research aircraft data is included in this directory.
