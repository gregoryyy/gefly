# Bounded studies

Each study must have one question, named candidates,
sources, a reproducible method, fixtures, proposed budgets and stop criteria before
running. End with a recorded review and architecture/product decision or an
explicit remaining uncertainty.

The [E1 engine study](e1-jsbsim/README.md) and [browser study](e1-browser/README.md)
investigate which dynamics/rendering arrangement supports a responsive,
repeatable web exercise. The [E2 mass-properties tool](e2-c172s/README.md) prepares
synthetic component arithmetic before aircraft inputs are available.
See [EVAL E1/E2](../docs/EVAL.md) and TODO 1.2/1.3. A study does
not silently select an aircraft, grow into a product or establish training credit.
