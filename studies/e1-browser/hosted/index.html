E1 browser check on the M1

Open this on the MacBook Pro M1 in Chrome (latest), plugged in, other tabs closed. Run the three steps in order, then copy each page's JSON into the chat.

1

JSBSim worker benchmark

Runs JSBSim v1.3.3 (WASM) in a Web Worker at a fixed 1/120 s step: two 30 s replays with the same input log, then a 10 s live run. Takes about 75 s. Results appear on the page as JSON.

Run worker benchmark
2

three.js scene driven by JSBSim

Calibrates the display refresh for 1 s, then renders a chase view at EDFE for about 20 s. The JSON panel appears bottom right when done. Keep the window at about 1440×900.

Run three.js render
3

CesiumJS scene driven by JSBSim

Same measurement with CesiumJS 1.146.0 on the WGS-84 ellipsoid, without Cesium ion or imagery.

Run CesiumJS render

CesiumJS loads its own workers and assets at run time. This page's host may block those loads; if the globe stays blank, note that and skip it. The local runner in the repo covers Cesium.
