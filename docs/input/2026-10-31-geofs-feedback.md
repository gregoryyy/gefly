# GeoFS strengths and gaps: original user feedback

Author: user. Recorded: 2026-10-31 15:09 Europe/Berlin by the orchestrator.
This is user experience and product direction, not an independently verified
inventory of the competing products. Preserve the original wording below.

geo-fs is actually a great start conceptually:

what I like:

- up and running as web application
- realistic geography -- to some degree
- controls via keyboard and touchpad, on mobile via orientation
- realistic physics -- to some degree
- different views incl. cockpit view
- video review feature
- ... research community for others

what I see as gaps:

- weather report and NOTAM
- realistic communication / can be via text
- navigation and glass cockpit basic functionality not implemented
- some key settings not implemented, like altimeters QNX and on maps the airport altitute
- checklists
- realistic maps with glide path
- typical drills, like flight patterns, approach ILS,&#x20;
- other advanced systems like ACAS, TCAS
- flight-gear has more realistic cockpit elements but with awful graphics and interaction
- controls and displays missing for navigation similar to classic plances like C172 or glass cockpit like A320 --> we want fewer types but more realistic controls
- VOR, DME etc. are only incompletely implemented in the visible cockpit
- navigation via real codes and fixes; real or generated map material
- ... research community for others
